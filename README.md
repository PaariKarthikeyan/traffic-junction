# Traffic Junction Simulator (Java 17, Swing)
Open the folder in IntelliJ IDEA / Eclipse as a Maven project, run `traffic.Main`.
Keys: 1-5 junction (4-way, T, Y, roundabout 4, roundabout 5) | N/M/H traffic | F/A/E signal mode | SPACE emergency vehicle.
Left-hand traffic; free left turn at signalised junctions. Same algorithm as the web version.
